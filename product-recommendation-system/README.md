# Product Recommendation System

A system that recommends products by learning user–item preferences from interaction patterns.


## Overview
- User–product interactions are represented as a matrix **R**

- Each value **r(u, p)** indicates interaction strength (e.g. views or purchases)

- Dimensionality reduction is applied using **Truncated SVD**:

    $$
    R \approx U_k \Sigma_k V_k^T
    $$

- Users are compared in latent space using **cosine similarity**:

    $$
    \text{sim}(u, v) = \frac{u \cdot v}{\|u\|\|v\|}
    $$

- Recommendations are generated by weighted aggregation of similar users’ preferences

- Entire dataset is generated locally to ensure full offline execution
